# Spec Delta

## Purpose

在一个页面中提交用户发言，并按后端事件流的实际顺序显示命令、子 agent 返回、结果作废和最终回答。

## ADDED Requirements

### Requirement: 页面读回已保存的会话
页面 SHALL 读取会话列表。选中会话后 MUST 显示已保存的用户发言、运行事件和最终回答，且 MUST NOT 为了显示这些内容重新执行研究流程。

#### Scenario: 重新打开后仍看到上一轮回答
- **WHEN** 后端已保存某会话的最终回答，用户重新打开页面并选中该会话
- **THEN** 页面显示该回答和已保存的运行事件

### Requirement: 页面提交当前发言
页面 SHALL 把用户输入的文字发送到当前会话。

#### Scenario: 提交输入框中的文字
- **WHEN** 用户在页面输入一段文字并提交
- **THEN** 客户端把这段文字发送到当前会话

### Requirement: 页面按收到的顺序显示事件
页面 MUST 按接收顺序显示命令已发出、命令被拒绝、子 agent 成功、子 agent 失败、结果作废和本轮结束。结果作废 MUST 显示在它之后收到的下一条命令之前。本轮结束时 MUST 显示最终回答。

#### Scenario: 作废显示在下一条命令之前
- **WHEN** 事件流依次包含一次子 agent 成功、结果作废、下一条命令已发出和本轮结束
- **THEN** 页面上结果作废出现在下一条命令之前，并显示最终回答

### Requirement: 页面不生成研究结论
页面 MUST NOT 自行补充论文检索、论文分析或研究方向结论。屏幕上的结论 MUST 来自本轮结束事件中的最终回答。

#### Scenario: 只显示事件中的回答
- **WHEN** 本轮结束事件带有最终回答
- **THEN** 页面显示该回答，且不另显示一份由页面生成的结论

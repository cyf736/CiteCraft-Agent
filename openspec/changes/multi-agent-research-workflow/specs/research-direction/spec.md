# Spec Delta

## Purpose

根据当前可用的检索结果和分析结果，给出有论文依据的研究空白、技术路线和创新点，供主 agent 组织最终回答。

## ADDED Requirements

### Requirement: 同时使用检索结果和分析结果
系统 SHALL 基于当前可用的检索结果和成功的分析结果产生研究方向结果，并且 MUST 同时使用这两组输入。

#### Scenario: 结果对应两组输入中的论文
- **WHEN** 检索结果和分析结果都可用，且研究方向命令执行成功
- **THEN** 研究方向结果所依据的论文都来自这两组当前输入

### Requirement: 结果包含空白、路线和创新点
成功的研究方向结果 MUST 分别给出研究空白、技术路线和创新点。每一项 MUST 标明至少一个来自当前输入的论文标识。系统 MUST NOT 把当前输入中不存在的论文写成依据。

#### Scenario: 三类内容都有论文依据
- **WHEN** 研究方向命令成功完成
- **THEN** 研究空白、技术路线和创新点各自标明至少一个当前输入中的论文标识

#### Scenario: 不引用输入之外的论文
- **WHEN** 当前检索结果只包含论文 A 和论文 B，且研究方向命令成功完成
- **THEN** 研究方向结果不把其他论文标为依据

### Requirement: 不改变检索和分析结果
研究方向执行期间 MUST NOT 发起新的检索、论文获取或入库，也 MUST NOT 替换已有分析结果。

#### Scenario: 执行后上游结果保持不变
- **WHEN** 研究方向命令成功完成
- **THEN** 检索结果和分析结果与调用前一致

### Requirement: 依据不足时明确说明
当前输入不足以支持某一项判断时，系统 SHALL 仍返回研究空白、技术路线和创新点三项，并在该项标明依据不足，而 MUST NOT 编造当前输入中没有的论文依据。

#### Scenario: 依据不足仍返回三项
- **WHEN** 当前分析只覆盖摘要切块，且不足以支持创新点
- **THEN** 结果仍包含创新点一项，并标明该项依据不足

# Spec Delta

## Purpose

解释主 agent 指定的、已经入库的论文，说明每篇论文的方法和主要结论，以及这些论文之间的关系。

## ADDED Requirements

### Requirement: 只分析命令点名的已入库论文
系统 SHALL 只分析当前可用检索结果里被本次命令点名的论文，并只读取这些论文已经入库的切块。系统 MUST NOT 为了分析重新获取或下载论文。

#### Scenario: 只覆盖被点名的论文
- **WHEN** 当前检索结果包含多篇论文，分析命令点名其中两篇
- **THEN** 分析结果只覆盖被点名的两篇论文，且不发生新的论文获取或入库

#### Scenario: 点名论文不在当前检索结果中
- **WHEN** 分析命令点名的论文不在当前可用检索结果中
- **THEN** 分析失败并交回主 agent，已有检索结果保持不变

### Requirement: 分析结果解释论文本身
成功的分析结果 MUST 包含每篇被分析论文的方法说明和主要结论。被分析论文多于一篇时 MUST 包含这些论文之间的关系。分析结果 MUST NOT 给出研究空白、技术路线或创新点。

#### Scenario: 两篇论文给出关系
- **WHEN** 两篇已入库论文被成功分析
- **THEN** 结果分别给出每篇论文的方法和主要结论，并给出二者之间的关系

#### Scenario: 单篇论文不编造对比
- **WHEN** 分析命令只点名一篇论文且分析成功
- **THEN** 结果给出该论文的方法和主要结论，并标明没有其他论文可比较

#### Scenario: 不产生创新点
- **WHEN** 分析成功完成
- **THEN** 返回给主 agent 的结果没有研究空白、技术路线或创新点结论

### Requirement: 只有摘要时标明正文缺失
被分析论文只有摘要切块时，系统 SHALL 基于摘要完成分析，并在结果中标明缺少正文切块。

#### Scenario: 摘要切块仍可分析
- **WHEN** 被点名论文只入库了摘要切块
- **THEN** 分析结果基于摘要，并标明该论文缺少正文切块

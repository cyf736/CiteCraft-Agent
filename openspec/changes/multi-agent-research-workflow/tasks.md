# Tasks

## 1. 图与状态

- [ ] 1.1 实现会话状态和命令守卫。验证：不调用模型的测试确认缺少检索结果时拒绝分析、缺少分析结果时拒绝研究方向、失败不覆盖已保存的成功结果、失败不能满足下游前置条件、检索成功后清掉已保存的分析结果和研究方向结果。
- [ ] 1.2 实现 `master`、`retrieval`、`analysis`、`direction` 的 StateGraph，子节点只回到 `master`。检索节点把 `query` 交给伪造的检索工具。验证：脚本化主 agent 跑通检索、分析、研究方向、结束；已保存的检索结果等于工具成功结果；一次控制权只执行一条命令。
- [ ] 1.3 实现每轮 8 次子 agent 调用上限，拒绝不计次，失败计次。验证：达到上限后不再执行检索，运行结束且回答说明达到上限。
- [ ] 1.4 记录 `command.issued`、`command.rejected`、`worker.completed`、`worker.failed`、`state.invalidated`、`run.completed`。验证：再次检索成功时，该次 `worker.completed` 和 `state.invalidated` 早于下一条 `command.issued`。

## 2. 分析与研究方向

- [ ] 2.1 实现分析节点，只读取命令点名且存在于当前检索结果中的论文切块，不调用检索工具；超长切块按顺序截断并标明。验证：伪造存储和模型的测试确认两篇论文含方法和关系、单篇标明无可比较、摘要切块标明缺少正文、越界论文使分析失败且已保存的检索结果不变、结果不含研究空白、技术路线或创新点。
- [ ] 2.2 实现研究方向节点，输出研究空白、技术路线和创新点，并用代码剔除当前输入之外的论文标识。验证：伪造模型返回未知论文时该标识被去掉，失去依据的项标明依据不足，且已保存的检索结果和分析结果保持不变。
